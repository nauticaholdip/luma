# Luma
LUMA is a clam shaped interactive lamp designed to guide users through a ten minute mindfulness ritual.
# My Role
I primarily worked on the physical prototype and 3D modelling alongside working with the team member doing the coding and hardware wiring to understand where each component needed to go and what openings or connections were needed. This helped me design and 3D model the shell around the hardware.
# Hardware 
Input
- TTP223 Touch sensor
- Push Button
- HC-SR04 Ultrasonic sensor
- Photoresistor

Output
- SG90 Micro Servo motor
- 8-LED NeoPixel ring
- DFPlayer Mini MP3

Controller
- Elegoo UNO R3

Software
- Arduino
- ProtoPie
